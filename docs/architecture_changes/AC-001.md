# AC-001 — Complete patch geometry

- Change ID: AC-001.
- Current specification: Roadmap §10.3 calls ceil(L/P) the number of complete patches.
- Observed issue: For L=9,P=8 there is one complete observed patch and one incomplete symbol, not two complete patches.
- Evidence that the issue is real: FACT: Euclidean division L=qP+r, 0<=r<P; q=floor(L/P).
- Proposed replacement: Use floor(L/P) for complete observed patches; ceil(L/P) only for padded storage slots, with an explicit padding policy.
- Mathematical justification: FACT: Euclidean division L=qP+r, 0<=r<P; q=floor(L/P).
