# Generic Mamba-2 and dense integration contract

Engineering reference: state-spaces/mamba v2.2.6 at d7b1ceb3c367ec9022925e812f507bcf706937c6. This is not a Bible version mandate. Exact retrieved sources and hashes are retained in evidence/mamba_integration/upstream/sources.json and the final integration evidence. Relevant sources: modules/mamba2.py (native step), modules/ssd_minimal.py (SSD duality), ops/triton/layernorm_gated.py (gate order), modules/block.py (pre-normalized residual convention). No upstream package or optimized kernel is installed.

The accepted subset is CPU FP32, full d_ssm=d_inner=2*d_model, one B/C group, D per head, convolution bias, no projection bias, SiLU, gated RMSNorm with eps=1e-5 and norm_before_gate=False. Layers use pre-RMSNorm and an explicit residual sum. There is no extra final trunk norm in the accepted inventory. This custom dense wrapper is not the upstream language-model architecture. Reduced precision, distributed execution and alternate SSM widths remain unsupported.

For layer input u[B,d], normalize u, then project and split [z,xBC,dt_raw] with widths [I,I+2*N,H]. The convolution stores the last K raw projected xBC values in oldest-to-newest order: [B,I+2*N,K]. Append the new projection and drop the oldest; multiply by the depthwise kernel, add bias, apply SiLU. Split the result into x[B,H,P], Bv[B,N], Cv[B,N], with I=H*P. Bv/Cv are shared across heads.

Use A=-exp(A_log), dt=softplus(dt_raw+dt_bias), decay=exp(dt*A). Canonical SSM state S has shape [B,H,P,N]. Update S'=decay*S + dt*x*Bv; read y=sum_N(S'*Cv)+D*x. Gate y by SiLU(z), then RMS-normalize over the full inner width, apply its learned weight, output-project, and add the original u. This is the upstream discrete input rule dt*B*x, not an exact-ZOH substitution. dt_bias uses inverse-softplus of log-uniform dt in [0.001,0.1]; exp(A_log) initializes uniformly in [1,16]; D initializes to one. dt_bias/A_log/D carry the upstream no-weight-decay metadata for later optimizer infrastructure. No optimizer is implemented now.

Step execution updates explicit tensors without in-place mutation. Zero initialization/reset means no previous convolution inputs or SSM history. Trunk state owns a typed tuple of layer states plus a processed-step count. Reset clears all rows/layers; selective row reset is outside this synchronous-batch interface. State snapshots are detached inference state, tagged by schema/config identity, and must be restored with identical weights. Validation checks type, layer count, batch, dimensions, FP32 CPU placement, finiteness and nonnegative step count. The count measures trunk inputs, including BOS, not payload patches alone.

Independent sequence execution uses batched convolution and the dense lower-triangular SSD identity: transition[t,s]=exp(sum_{j=s+1..t} dt_j*A). A stable triangular segment sum avoids subtracting large prefix sums. The output is the weighted sum of all prior dt_s*x_s*B_s contributions contracted with C_t, plus decayed incoming S and D*x. Final state is computed from the last transition row. This O(T^2) reference path is intended for bounded validation/chunks, not a claim of long-sequence efficiency. It does not call the production step loop.

The full dense wrapper owns ByteHierarchy and SharedMambaTrunk once each. It processes the learned BOS d_model vector through zero-initialized shared state before calling ByteHierarchy.start with explicit Mamba context. Each consume handles at most one completed event internally and immediately processes it exactly once before conditioning the next patch. An integrated state is always ready for local prediction; shared.steps=1+hierarchy.completed_patches. Export/restore includes both owners' states and validates this relationship. No external event replay API exists in this wrapper.

The differentiable full forward encodes only complete patches that precede a prediction, prepends BOS to the trunk sequence, and uses context_j solely for local patch j. Independent incremental execution predicts before consuming each symbol. PAD and BOS never count as payload slots. All row lengths are equal; callers group ragged inputs as in the accepted byte contract.

Predeclared numerical tolerance: FP32 atol=1e-5, rtol=1e-4. Measure both absolute error and relative error with denominator max(abs(reference),1e-8); relative error near zero is diagnostic, while torch.assert_close enforces the combined gate. Reject nonfinite intermediate/output/state values rather than clamp them. Runtime process RSS and training readiness remain unverified. Source/equation parity is separate from upstream package-runtime parity.
