## Checkpoints and exact resume

Checkpoint schema 1 captures model weights, optimizer groups/moments and ordered per-parameter update counts, scheduler, global/micro/example/byte counters, accumulation position, resolved/training configs, parameter structure, dataset hash, Python/Torch CPU RNG, data ordering/cursor, code/environment, run ID, semantic metrics and elapsed time. Run identities include UUID, UTC creation time, commit and dirty state, source/config/dataset hashes, Python/PyTorch/device/profile, seed and parameter count. Every resumed run records its parent checkpoint.

Only completed optimizer boundaries are supported: accumulation position zero and gradients cleared. State plus an integrity manifest is written and fsynced in a private sibling directory, checked for readability, then atomically renamed to an unused checkpoint directory. Existing run/checkpoint identities are refused. Corruption and incompatible model, training, manifest, source, environment, optimizer, scheduler, counters or schema fail explicitly. Publication-failure testing preserves the earlier checkpoint and cleans the private temporary directory.

The resumed edge-case review demonstrated two real defects in the original validator's assumptions: five-byte windows can leave the patch encoder without AdamW state, while a 32-byte window plus seven-byte tail can give it only one update at global step two. The corrected validator preserves lazy state, validates exact active-state coverage against per-parameter counts, and accepts counts below the global step. Both continued runs now match uninterrupted parameters, optimizer, scheduler, cursor and semantic metrics exactly. Deleted state, invalid counts and malformed moments remain rejected.

The hard gate compares six continuous optimizer updates with three updates, save, trainer destruction/recreation and three resumed updates. Final parameters, AdamW moments/counts, RNG tensors, scheduler, data cursor, counters, next batch and semantic metrics match exactly: **maximum tensor difference 0.0**. The ordinary four-update/two-update split gate also passes. Wall-clock measurements and run identity/time are deliberately excluded from semantic equality; no tolerance was introduced for resume.
